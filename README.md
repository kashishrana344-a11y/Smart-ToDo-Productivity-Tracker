Flowday – Smart To-Do & Productivity Tracker

Project Overview

Flowday is a productivity management application designed to help users organize their daily tasks, manage priorities, and improve time management.

Features

- User Registration and Login
- Task Management
- Priority-based Task Organization
- Pomodoro Timer
- Productivity Tracking
- Database Management
- User-friendly GUI

Technologies Used

- Python
- Python GUI Framework
- Database Management

Project Purpose

The main objective of this project is to improve productivity by helping users manage tasks efficiently and track their progress.
